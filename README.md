## 🏛️ Brand Heritage & Design System

- **Category Scope:** Women's Ethnic Fashion — **Sarees & Suits only**.
- **Palette Tokens:**
  - **Canvas:** Pure White (`#FFFFFF`) & Subtle Ivory (`#FBF9F5`)
  - **Accents:** Antique Gold (`#B89758`, `#8C6D36`)
  - **Typography & Structure:** Deep Heritage Brown (`#2A1B14`, `#1A110D`)
- **Typography:** *Cormorant Garamond* (Editorial display), *Cinzel* (Imperial heritage headers), *Montserrat* (Functional sans-serif UI).
- **Logo:** Exact vector geometry preserved from official atelier trademark.

## 💎 Features & Architecture

1. **Editorial Homepage:**
   - Cinematic hero presentation with staggered typography entrance.
   - 3D perspective category showcases (Sarees Guild & Suit Atelier).
   - Featured handloom collections with instant quick-add & secondary image preview.
   - Atelier heritage story & artisan purity guarantees.
   - Verified trust factors and dark heritage-brown footer.

2. **Catalog & Discovery:**
   - Multi-facet filtering by category, fabric (Mulberry Silk, Katan Silk, Chanderi, Organza, Tussar, Micro-Velvet, Georgette), and price.
   - Mobile-first slide-in filter drawer.
   - Real-time catalog search modal with instant suggestions.

3. **Product Detail Page (PDP):**
   - High-resolution multi-angle studio photography.
   - Dynamic pincode delivery estimator across India.
   - Size selector (Free Size with unstitched blouse for Sarees; XS–XXL for Suits).
   - Direct *Add to Bag*, *Buy Now*, and *Wishlist* actions.

4. **Cart, Checkout & Payments:**
   - Slide-in Cart Drawer with complimentary shipping threshold indicator.
   - Full checkout flow with genuine payment methods:
     - **Cash on Delivery (COD)** with telephonic verification.
     - **Direct Bank Transfer / UPI** with official studio banking details.
   - No fake/simulated payment success — real studio order reference generation (`BS-XXXXXX`).

5. **Client Concierge & Policies:**
   - **Live Order Tracking:** Real-time consignment milestone progression and WhatsApp concierge lookup.
   - **Patron Account:** Saved order history and address book.
   - **Transparent Policies:** 4–7 business days express delivery, 7-day hassle-free exchange policy.
   - Direct WhatsApp Concierge hotline integration (+91 7827533877).

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/mayanksinghal007/balaji-signatuer-v2.git
cd balaji-signatuer-v2

# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
npm start
```
